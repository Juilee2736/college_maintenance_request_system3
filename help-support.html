Help & Support

Get help with submitting and tracking maintenance requests.

How to Submit a Maintenance Request

Follow these simple steps to report a maintenance problem:

  1. Click on New Request.
  2. Enter a short and clear title for the problem.
  3. Enter the correct location, room number or building.
  4. Select the appropriate maintenance category.
  5. Describe the problem clearly.
  6. Upload a photo if it helps explain the problem.
  7. Click Submit Request.

How to View My Requests

To view the maintenance requests submitted by you:

  1. Click on My Requests.
  2. You can see all your submitted requests.
  3. Use the search box to find a particular request.
  4. Use the filter to view requests by status.

How to Track a Request

Every submitted maintenance request has a unique Request ID.

  1. Go to the Dashboard.
  2. Find the Track Request section.
  3. Enter your Request ID.
  4. Click Track.
  5. The current status of your request will be displayed.

Request Status

  • Pending: Your request has been submitted and is waiting for action.
  • In Progress: The maintenance team is working on the issue.
  • Completed: The maintenance work has been completed.

Important Tips

  • Enter the correct room number and location.
  • Provide a clear description of the problem.
  • Upload a clear photo when required.
  • Check whether the same problem has already been reported.
  • Keep your Request ID for future reference.
  • Do not submit duplicate requests for the same problem.

Need Further Assistance?

If you are unable to submit a request or the issue requires immediate attention, contact the concerned college staff or maintenance department.

Please provide your Request ID when asking about an already submitted request.
